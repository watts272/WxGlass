# WxGlass — 微信液态玻璃 UI 模块

LSPosed/Xposed 模块（也可经 LSPatch 内嵌）。作用域：`com.tencent.mm`。

## 已实现
- **玻璃底板**：半透明渐变 + 1dp 高光描边 + 大圆角 + 悬浮阴影（深浅色自适应）
- **底部 Tab** → 悬浮玻璃胶囊
- **头像** → iOS 连续圆角
- **对话框/弹窗** → 圆角玻璃 + 背景模糊（Android 12+）
- **Telegram 风格弹簧动效**：按压缩放回弹、页面右侧阻尼滑入、弹窗缩放弹出

## v0.2 新增（参考 iOS 液态玻璃效果）
- 列表（会话/通讯录/发现/我）→ 分组圆角卡片，连续行合成一张卡，遇到标题/横幅自动断开
- Tab 选中项灰色胶囊高亮，切换时随 setSelected 刷新
- 顶部右侧按钮组 → 玻璃胶囊；单个图标按钮（返回/加好友/相机）→ 圆形玻璃按钮
- 搜索栏 → 白色胶囊
- 聊天气泡 → 半透明胶囊（发送=蓝，接收=白），输入框 → 玻璃胶囊
- 全部颜色走 `Palette.kt`，浅/深色自动切换
- 聊天壁纸请用微信自带「聊天背景」设置，模块不管壁纸

## 构建
1. 推到 GitHub，Actions 自动产出 `WxGlass-apk`（debug 签名，可直接安装）。
2. 或本地装好 Android SDK 后：`gradle :app:assembleDebug`

## LSPatch 集成（在你自己的手机上操作）
1. 安装 LSPatch 管理器，先安装你自己从官方渠道下载的微信。
2. 安装 WxGlass APK。
3. LSPatch →「修补」→ 选微信 → 选「本地模式/集成模式」→ 勾选 WxGlass → 开始。
4. 卸载原版微信（会丢本地数据，先备份聊天记录），安装修补后的 APK。

## 已知限制
- **不是真正的背板模糊**：普通 View 无法做 backdrop blur，主界面用半透明渐变近似；仅弹窗用系统 blur-behind。
- 微信类名/ID 混淆，识别规则在 `Targets.kt`，换版本识别不准时改这里。
- 未改微信布局文件，所以不是「整体重构」，而是在原 UI 上叠加样式与动效。
- 微信有完整性校验，LSPatch 重签后可能被风控，请使用小号。
